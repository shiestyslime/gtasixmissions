## Why is Save Game greyed out? {#save-greyed-out}

If an objective is active, finish the mission and try again in free roam. Manual saving is normally unavailable in missions. A checkpoint can let you retry the current section before manual saving becomes available again. {src:1,3,4}

## Which save slot should I use? {#choose-a-slot}

Use an empty slot before starting a mission you might want to revisit. PC Gamer and PowerPyx counted **15 manual slots**. Pick one for your current playthrough and leave your earlier save in a different slot. {src:1,2}

## How do I load a save without losing today's progress? {#load-an-older-save}

First, save your current progress in its own manual slot. Then open **Game → Load Game** and choose the earlier file. GTA VI keeps a single autosave. PowerPyx found that loading an older game can replace that autosave, so keep any point you want to return to in a manual slot. {src:1,2,3}

## Can I replay a completed mission? {#mission-replay}

PowerPyx found no mission-select replay option in its launch playthrough. If you made a manual save before a mission, load that file to play it again. For an objective you are still playing, see [checkpoint retries](/missions/#checkpoint-or-replay). {src:1,4}
